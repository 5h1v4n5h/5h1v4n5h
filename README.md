### 🚀 About Me

Hey there! 👋 I am a **Software Engineer** specializing in **Distributed Systems**, **Cloud-Native Backends**, and **Autonomous AI Agents**.

- 🔭 **Currently Building**: [Agent Apply](https://github.com/5h1v4n5h/Agent_Apply) — A local-first autonomous job application agent powered by RAG applicant memory, evidence-grounded document generation, and HITL review gates.
- ⚡ **Core Focus**: High-throughput microservices, event-driven architectures, pgvector semantic search, and resilient background worker swarms.
- 🛠️ **Tech Philosophy**: Obsession with zero-hallucination agent architectures, clean API design, and rock-solid production reliability.
- 🎓 **Research**: Author of multiple IEEE Access publications in Computer Vision & Edge Systems.
